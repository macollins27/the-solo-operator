# Templates

These templates are reusable artifacts students can carry from the course into their own projects.

They are intentionally plain markdown. The student should copy the shape, then author the contents from their own project and incidents.

## Files

- `AGENTS.md` — vendor-neutral repository instructions for AI coding agents.
- `CLAUDE.md` — Claude Code-specific operating rules.
- `code_review.md` — reusable review protocol for AI-authored or human-authored changes.
- `agent-setup-checklist.md` — repo readiness checklist before asking an agent to work.
- `ai-ready-ticket.md` — task/issue format for local, cloud, or background agents.
- `security-boundaries.md` — security rules for agent data, filesystem, network, MCP, and plugins.
- `workflow-eval.md` — eval format for deciding whether a workflow is reusable or automatable.
- `learnings.md` — scratch layer for observations before promotion into rules, skills, hooks, or tools.
- `subagent-dispatch.md` — four-part dispatch contract for Task subagent dispatches (long-context or minimal-context).
- `worktree-plan.md` — isolation plan for parallel write agents.
- `pr-description.md` — structured PR summary for AI-authored or AI-assisted changes.
- `governance-audit-log.md` — audit entry shape for agent-authored, AI-reviewed, or AI-committed work.
- `cost-controls.md` — model-tier, budget, retry, and stop-condition policy.
- `mcp-tool-contract.md` — design/audit shape for MCP tools used by nondeterministic agents.

## Rule

Templates are starter shapes, not authority.

The operator authors the final version. An AI may draft, but the human cuts, signs, and owns the rules.
